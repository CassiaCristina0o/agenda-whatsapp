# Versão CLI - Antes da API

## Objetivo

Registrar a versão funcional da Agenda antes da migração para uma API.

## Funcionalidades demonstradas

* Cadastro de eventos.
* Listagem de eventos.
* Exclusão de eventos.
* Persistência em SQLite.
* Padronização automática de datas.
* Padronização automática de horários.

## Demonstração

O vídeo apresenta o funcionamento da Agenda diretamente pelo terminal, demonstrando o fluxo de cadastro, consulta e exclusão de eventos.

A próxima etapa do projeto será a implementação da API, preparando a aplicação para a integração com o WhatsApp.
